CPX 프롬프터 설명서

이 설명서를 따라 하면 내 CPX 대본을 프롬프터에 띄워 놓고 촬영할 수 있습니다. 컴퓨터를 잘 몰라도 순서대로만 하면 됩니다.

  1. 1. 대본을 프롬프터 파일로 바꾸기Word 대본을 프롬프터가 읽는 파일(.json)로 바꿉니다
  2. 2. 프롬프터에 불러오기만든 파일을 프롬프터에 넣습니다
  3. 3. 촬영할 때 쓰는 법재생, 속도, 글자 크기, 거울 모드
  4. 4. 자주 묻는 질문안 될 때, 다른 기기에서 쓸 때

1. 대본을 프롬프터 파일로 바꾸기

바꾸는 방법은 두 가지입니다. 하나만 고르세요.

방법 A. Claude Code (추천)

Claude 유료 요금제(Pro 이상)가 있으면 이 방법을 쓰세요. 문장 하나를 붙여 넣고 대본 파일을 끌어다 놓으면 끝입니다. 설치는 없고, 틀린 곳 검사까지 알아서 합니다.

방법 B. 채팅 AI

유료 요금제가 없으면 ChatGPT나 Claude 채팅을 쓰세요. 설치는 없고, 복사와 붙여 넣기를 몇 번 합니다.

방법 A. Claude Code로 바꾸기

A-1은 처음 한 번만 하면 됩니다. 다음 대본부터는 A-2만 하세요.

A-1. Claude 앱 설치하기

  1. Claude 내려받기 페이지에서 내 컴퓨터(Mac 또는 Windows)에 맞는 Claude 앱을 받아 설치합니다.
  2. Claude 앱을 열고 유료 요금제(Pro 이상) 계정으로 로그인합니다. 무료 요금제에서는 Claude Code를 쓸 수 없습니다.
  3. 앱 위쪽에서 Code 탭을 누릅니다. 아래쪽에 글을 쓰는 입력창이 보이면 됩니다.

A-2. 대본 바꾸기 (대본마다)

  1. Code 탭에서 새 세션을 엽니다. 폴더를 고르는 칸이 있으면 대본 파일이 있는 폴더(예: 다운로드)를 고릅니다. 이 칸은 입력창 아래에 있습니다.
  2. 아래 변환 문장 복사 버튼을 누릅니다.
https://github.com/ChangwooLim/cpx-prompter/tree/main/skill/prompter 에 있는 SKILL.md와 prompt.md를 요약하지 말고 원문 그대로 읽은 다음, SKILL.md 순서대로 아래 대본을 프롬프터 JSON 파일로 만들어줘. 결과 파일은 대본과 같은 폴더에 저장하고, 다른 프로그램은 설치하지 마.
대본 파일:
  1. Code 탭의 입력창을 누르고 붙여 넣습니다. Mac은 ⌘ + V, Windows는 Ctrl + V입니다. 입력창 맨 끝이 "대본 파일:"로 끝나 있으면 됩니다.
  2. Finder(Mac) 또는 파일 탐색기(Windows)에서 대본 Word 파일(.docx)을 입력창으로 끌어다 놓습니다. "대본 파일:" 뒤에 파일 이름이 붙습니다. 끌어다 놓기가 어려우면 파일 이름을 직접 써도 됩니다. 예: 다운로드 폴더의 주요우울장애 대본.docx
  3. Enter 키를 누릅니다.
  4. Claude가 "이 명령을 실행해도 될까요?"처럼 허락을 물으면 허용(또는 Yes, Allow)을 누릅니다. GitHub에서 규칙 파일을 받거나 결과 파일을 저장할 때 몇 번 물어봅니다. 1~2분 뒤 Claude가 "다운로드 폴더에 주요우울장애 대본.prompter.json을 만들었다"처럼 알려 줍니다. 이 파일이 프롬프터 파일입니다.
  5. Claude가 "확인할 점"을 알려 주면 읽어 봅니다. 대본 순서가 이상한 곳, 누가 말하는지 헷갈리는 곳을 알려 줍니다. 대사는 원래 대본 그대로 옮기고 고치지 않습니다.

다 됐으면 2. 프롬프터에 불러오기로 가세요.

방법 B. 채팅 AI로 바꾸기

  1. 아래 프롬프트 복사 버튼을 누릅니다. 긴 안내문이 복사됩니다.
대본을 프롬프터 양식으로 바꾸는 규칙이 담긴 안내문입니다. 내용은 여기에서 볼 수 있습니다.
  1. ChatGPT나 Claude에서 새 채팅을 엽니다.
  2. 입력창에 붙여 넣습니다.
  3. 같은 메시지에 대본 Word 파일을 첨부합니다. 첨부가 안 되면 대본 내용을 복사해서 안내문 아래에 붙여 넣습니다.
  4. 보냅니다. 답에 json이라고 적힌 회색 상자가 나옵니다.
  5. 그 상자 오른쪽 위의 복사 버튼을 누릅니다.
  6. 프롬프터를 열고 대본 불러오기를 누릅니다.
  7. 붙여 넣기 칸에 붙여 넣고 붙여 넣은 내용 추가를 누릅니다. "불러옴"이 보이면 끝입니다. 3. 촬영할 때 쓰는 법으로 가세요.

2. 프롬프터에 불러오기

  1. 프롬프터를 엽니다.
  2. 위쪽의 대본 불러오기를 누릅니다.
  3. JSON 파일 고르기를 누르고, 1번에서 만든 .prompter.json 파일을 고릅니다. 파일을 프롬프터 화면 위로 끌어다 놓아도 됩니다. 초록색으로 "불러옴 · 대본 이름 · 몇 구간 · 길이"가 보이면 성공입니다.
  4. 닫기를 누릅니다. 왼쪽 위 목록에 내 대본이 선택되어 있습니다.
빨간 글씨가 나오면 파일에 틀린 곳이 있다는 뜻입니다. 빨간 글씨는 몇 번째 구간, 몇 번째 줄이 틀렸는지 알려 줍니다. 그 글을 복사해서 Claude Code나 채팅 AI에 붙여 넣고 "이거 고쳐줘"라고 하면 됩니다.

불러온 대본은 지금 쓰는 기기의 브라우저에만 저장됩니다. 인터넷 어디에도 올라가지 않습니다. 다음에 같은 기기로 열면 그대로 남아 있습니다.

3. 촬영할 때 쓰는 법

  1. 프롬프터를 띄운 노트북이나 태블릿을 카메라 바로 뒤에 둡니다.
  2. 왼쪽 위 목록에서 내 대본을 고릅니다.
  3. ▶ 시작을 누르면 대본이 천천히 올라갑니다. 화면을 한 번 탭해도 멈추고 다시 움직입니다.
  4. 화면 가운데 밝은 띠에 온 줄을 읽습니다.

위쪽 버튼은 이렇게 씁니다.

대본 안의 표시는 이런 뜻입니다.

  • 회색 괄호 (미소)는 연기 지시입니다. 소리 내 읽지 않습니다.
  • 점선 상자 체크 3, A1은 채점 항목이나 진단기준 번호입니다. 읽지 않습니다.
  • 주황 상자 생략 가능이 붙은 대사는 시간이 모자라면 건너뜁니다.

4. 자주 묻는 질문

폰이나 태블릿에서도 쓰고 싶어요.
만든 .prompter.json 파일을 그 기기로 보냅니다(카카오톡 나에게 보내기, 메일 등). 그 기기에서 프롬프터를 열고 2. 프롬프터에 불러오기를 한 번 더 합니다. 기기마다 따로 불러와야 합니다.
대본을 고쳤어요.
고친 Word 파일로 1번을 다시 하고, 새 파일을 다시 불러옵니다. 대본 이름이 같으면 예전 것을 덮어씁니다.
목록에서 대본을 지우고 싶어요.
대본 불러오기를 누르고, 불러온 대본 목록에서 지울 대본의 삭제를 누릅니다.
대본이 10분을 넘어요.
주황 생략 가능 대사를 건너뛰거나 속도를 조금 올립니다. 프롬프터는 대사를 지우지 않습니다. 대사를 줄이려면 Word 대본을 고친 뒤 다시 바꿉니다.
Claude가 GitHub 파일을 읽지 못했다고 해요.
허락을 물을 때 거부를 누르지 않았는지 확인하고, A-2를 처음부터 다시 합니다. 그래도 안 되면 방법 B를 씁니다.
Claude가 무언가를 설치하겠다고 해요.
거부(또는 No)를 누르고 "설치하지 말고 해줘"라고 씁니다. 따로 설치할 것 없이 동작합니다.
내 대본이 다른 사람에게 보이나요?
아니요. 불러온 대본은 지금 쓰는 기기의 브라우저에만 저장됩니다. 프롬프터 사이트에는 아무것도 올라가지 않습니다.
